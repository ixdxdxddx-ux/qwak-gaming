Проблема, которую я вижу:





По твоему скриншоту в index.html сейчас два навбара подряд.



В них дублируются id="navAuth" и id="navLinks".



js/auth.js делает querySelector('#navAuth'), значит он всегда берёт только первый найденный блок и рендерит кнопки не туда.



Плюс js/utils.js ждёт #burgerBtn и .nav-link, а у тебя в старой вёрстке видно burger и nl, то есть HTML и JS сейчас из разных версий.



Отдельно: raw-файл из GitHub указывает, что в репозитории index.html вообще без навбара, значит локальная версия и версия в репо уже расходятся. Важно править именно тот файл, который реально открывает сайт.

План исправления:





Удалить вручную вставленный верхний <nav class="navbar" ...>...</nav>.



Оставить только один рабочий навбар.



В этом навбаре оставить только один контейнер авторизации:

\<div id="navAuth"></div>



Не держать внутри #navAuth статичные кнопки Войти/Регистрация — их сам вставляет Auth.renderNav().



Привести селекторы HTML к тем, которые ждёт текущий JS:





ссылки меню: class="nav-link"



контейнер ссылок: id="navLinks"



бургер: id="burgerBtn"



auth-контейнер: id="navAuth"

Минимальная целевая структура:

<nav>
  <a href="index.html">QWAK</a>

  <div id="navLinks">
    <a class="nav-link" href="index.html">Главная</a>
    <a class="nav-link" href="pages/games.html">Игры</a>
    <a class="nav-link" href="pages/forum.html">Форум</a>
    <a class="nav-link" href="pages/launcher.html">Лаунчер</a>
  </div>

  <div id="navAuth"></div>

  <button id="burgerBtn">...</button>
</nav>

Почему это решит баг:





Auth.renderNav() из js/auth.js вставляет кнопки именно в #navAuth.



Сейчас из-за дублей и смешанной старой/новой вёрстки кнопки попадают в неправильный блок или выглядят как “пропавшие”.



После нормализации HTML кнопки снова будут рендериться и стилизоваться через .btn, .btn--outline, .btn--primary.

Технически:





js/auth.js: ищет #navAuth, навешивает события на #loginBtn и #regBtn



js/utils.js: активную ссылку ищет по .nav-link, бургер по #burgerBtn



Поэтому safest-вариант — не переписывать JS, а подогнать HTML под уже существующие селекторы

Что проверить после фикса:





справа в навбаре видны две нормальные кнопки, а не просто тёмный текст;



клик по “Войти” открывает окно логина;



клик по “Регистрация” открывает окно регистрации;



в DevTools поиск по #navAuth показывает только один элемент.
